# NORDWOOD WEB

Official website source for NORDWOOD — an industrial parquet production platform in North Macedonia, developed for European B2B markets.

## Live website

https://nordwood-web.itonijao.chatgpt.site

## Website

The project includes dedicated pages for:

- Home
- About NORDWOOD
- Production
- Capabilities
- Collections
- Contact

The website uses the official NORDWOOD brand assets and company-profile information provided for the project.

## Technology

Built with React, Next.js/Vinext, TypeScript and CSS.
